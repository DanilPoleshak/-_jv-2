# -_jv-2
Создание моделирующую обучение мыши в лабиринте методом подкрепления. Лабиринт генерируется произвольного размера; его размеры и схема задаются пользователем. Задача мыши собрать водичку и дойти до сыра кратчайшим путем.
На каждом шаге мышь выбирает одно из доступных направлений движения. Среда возвращает подкрепление — численную оценку выигрыша или проигрыша. На основе полученной обратной связи мышь постепенно обучается выбирать действия, которые приводят к сбору воды и достижению сыра с максимальной суммарной наградой.
